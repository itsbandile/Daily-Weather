🌤️ Daily Weather

A modern, responsive weather app that gives you live conditions and smart forecasts for wherever you are.

## Features

- 📍 Automatic location detection, plus city search
- 🌡️ Current temperature, feels-like, wind, humidity, sunrise and sunset
- ⏰ Hourly forecast for the day, with a temperature trend chart
- 📅 7-day forecast with rain chances and UV index
- 🌧️ Rain probability timeline
- 💡 Rotating weather insights (storms, UV warnings, temperature changes)
- ⭐ Save and revisit favorite locations
- 🌙 Dark mode

## Built With

- React + Vite
- Open-Meteo API (weather and geocoding)
- OpenStreetMap Nominatim (location names)

## Getting Started

```bash
npm install
npm run dev
```
